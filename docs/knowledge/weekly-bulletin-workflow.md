- **PDF generation:** `"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless --disable-gpu --no-pdf-header-footer --print-to-pdf=<out.pdf> file://<abs-path>.html`, run from the week's folder (QR/logo images use relative paths `MI2 QR CODE.png`, `../../logo.png`, `../../qrcode.png`).
