On 2026-08-29 the bulletin site was rethemed from parchment/burgundy (scroll) + navy/gold (Tailwind) to match the new Wix website at https://www.fpccorinth.org. Source of truth on the Wix site: `--color_30` = sage `#6d8c83` (nav text, GIVE button, hero text, footer fill), `--color_15` = ink `#171200`, `--color_14` = `#666558`, `--color_13` khaki `#b0af9b`, `--color_18` olive-gold `#847539`, `--color_12` cream `#fffeed`; type is Work Sans (headings semibold / extralight) with DIN Next Light body.

Bulletin mapping (documented in `prompt.md` "Design Tokens"): `--accent #6d8c83` for fills, `--accent-deep #56736a` for small text (the raw sage is only 3.6:1 on white — fails AA for labels), Work Sans for eyebrows/labels/display titles, EB Garamond kept for body copy (echoes the serif logo wordmark; better for long liturgy reading).

**How to apply:** New weekly scroll bulletins copy the previous week's file, so the palette carries forward automatically — but if one is ever built from an old file, check for `#8b1a1a` / `#b8963e` / Cinzel / Cormorant and re-run the mapping.
